# schemas/

Versioned dataset schemas and fixtures. The CI schema-validation hook lists
this directory; P9/P13 extend validation.

- `pedagogical_sample.v2.schema.json` — JSON Schema (draft 2020-12) for one
  `records.jsonl` line. Human reference is `docs/DATA_SCHEMA.md`.
- `records.example.v2.json` — canonical valid example record (from
  `docs/DATA_SCHEMA.md`). Used by unit round-trip tests; must always validate
  against the schema above.

Room database schema exports live separately in `app/schemas/` (generated by
KSP, committed, used by migration tests). They are database schemas, not
dataset schemas — do not mix the two.
